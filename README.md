# Aeg – erster Prototyp

Eine kleine, kindgerechte Lern-Web-App mit Demo-Chat, Lernhelfer, Fokus-Timer und Mutmachern. Sie arbeitet vollständig lokal und verwendet keine KI-API.

## Starten

1. Im Projektordner die Datei `index.html` doppelklicken.
2. Die App öffnet sich im Standardbrowser.

Alternativ kann `index.html` in einen Browser gezogen werden.

## Dateien

- `index.html` – Aufbau und Inhalte der App
- `style.css` – Gestaltung und Darstellung auf kleinen Bildschirmen
- `script.js` – Demo-Chat, Lernübungen, Timer und Mutmacher
- Das Roboter-Logo ist direkt in `index.html` eingebaut.

Hinweis: Der Chat enthält absichtlich nur einfache lokale Demo-Antworten. Eine echte KI-Anbindung kann später ergänzt werden.
